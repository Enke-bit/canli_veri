1.4 SQL Server Express 2022 kurulumu (yönetici izni gerekir)

  1. Microsoft'un resmî indirme sayfasından SQL Server 2022 Express kurulumunu indirin.
  2. Kurulum türü olarak Basic seçin. Örnek (instance) adı SQLEXPRESS olsun.
  3. Kurulum bitince services.msc açın → SQL Server (SQLEXPRESS) servisinin Running olduğunu doğrulayın.
  4. Sunucu adı olarak .\SQLEXPRESS kullanılacak. Windows Authentication varsayılan ve yeterlidir.
Bu adımı sizin yapmanız gerekir. Yönetici izni olmadan kurulum yapılamaz. Kurulum bittikten sonra kılavuzun geri kalanına devam edin; proje tarafında ek bir işlem gerekmez.

1.5 ODBC sürücüsü

PowerShellkurulu sürücüler
Get-OdbcDriver | Where-Object {$_.Name -like '*SQL Server*'} | Select-Object Name,Platform
ODBC Driver 17 for SQL Server 64-bit ODBC Driver 18 for SQL Server 64-bit

En az bir sürücü görünmelidir. Hiçbiri yoksa Microsoft ODBC Driver 18 for SQL Server kurun (yönetici izni gerekir). Kurduğunuz sürücünün adını .env içine aynen yazacaksınız.

17 mi 18 mi? Kod ikisiyle de çalışır. 18'de şifreleme varsayılan olarak zorunludur. Eski LocalDB + 17 kombinasyonunda "Encryption not supported" hatası alırsanız 6. adımdaki DB_ENCRYPT=false ayarını kullanın.

1.6 SSMS (isteğe bağlı)

Veriyi gözle görmek için SQL Server Management Studio kurun. Zorunlu değildir; panel ve API'ler veriyi zaten gösterir. SSMS'te .\SQLEXPRESS veya (localdb)\MSSQLLocalDB sunucusuna Windows Authentication ile bağlanın.

10 Paneli açın ve doğrulayın

Tarayıcıda: http://127.0.0.1:8000/dashboard

Görmeniz gerekenler:

  • Üst şerit: “Canlı · iki API çevrimiçi”, kaynak API'de 3/500/2000.
  • Hedef API: “Çevrimiçi · MSSQL” ve DB: DentSyncDemo.
  • Metrikler: 3 klinik, 500 hasta, 2.000 randevu.
  • Durum grafiği: Scheduled/Confirmed/Completed/Cancelled dilimleri.
  • Senkronizasyon başarısı: %100 (ilk kurulumda başarısız tur yoksa).
  • Canlı akışta son SyncLog kayıtları.
Panelde sahte veri yoktur. Hedef API kapalıysa kırmızı uyarı çıkar ve metrikler — olur; bu bir hata değil, dürüst davranıştır. Veri görünmüyorsa 9. adımı çalıştırıp sayfayı yenileyin.

Panelin altındaki “Uçtan uca deneme” bölümünde bir randevu seçip:

  1. Kaynakta iptal et → kaynak API'de iptal + otomatik senkronizasyon + hedef API doğrulaması.
  2. Kaynakta işlem türünü değiştir → güncelleme + senkronizasyon.
  3. Senkronize et → yalnızca senkronizasyon.
  4. Hedef API'de Confirmed yap → MSSQL'de durum değişikliği (kaynak sonra gönderirse kaynak kazanır).

12 Sürekli çalışma: Windows Task Scheduler

Kaynak API ve MSSQL açıkken senkronizasyonu her 5 dakikada bir otomatik çalıştırın. Yönetici izni gerekmez; görev yalnızca sizin kullanıcınız için oluşturulur.

PowerShellgörevi kur + hemen bir kez çalıştır
.\scripts\register_sync_task.ps1 -IntervalMinutes 5 -RunNow
Gorev adi : DentSync - API to MSSQL Komut : "C:\...\.venv\Scripts\python.exe" "C:\...\scripts\sync_api_to_mssql.py" Aralik : her 5 dakika SUCCESS: The scheduled task "DentSync - API to MSSQL" has successfully been created.

Kontrol ve kaldırma:

PowerShellgörev yönetimi
schtasks /Query /TN "DentSync - API to MSSQL" /V /FO LIST
.\scripts\unregister_sync_task.ps1
Görev yalnızca oturum açıkken çalışır. Bilgisayar uykuya girerse çalışmaz; uyandığında sonraki tetikleme devreye girer. Kaçan veri olmaz, çünkü checkpoint kaybolmaz ve örtüşme penceresi vardır.

12.1 Görev çalışırken ne oluyor?

DurumSistem davranışı
Kaynak API kapalıSınırlı retry → SyncLog = Failed, çıkış kodu 1. Checkpoint ilerlemez. API açılınca sonraki tur tüm bekleyen veriyi alır.
MSSQL erişilemezÇıkış kodu 2, net bağlantı hatası. Hiçbir iş “başarılı” yazılmaz.
Önceki tur bitmedilogs\sync.lock nedeniyle yeni tur başlamaz (çıkış kodu 3). Kilit 1 saatten eskiyse otomatik devralınır.
Aktarım yarıda kaldıSayfa transaction'ı geri alınır; o türün checkpoint'i ilerlemez; sonraki tur aynı veriyi yeniden işler (upsert güvenli).

13 Günlük kullanım: başlat / durdur

Başlatma sırası

  1. MSSQL servisi çalışıyor mu? (Get-Service *SQL*)
  2. Pencere 1: .\scripts\run_source_api.ps1
  3. Pencere 2: .\scripts\run_target_api.ps1
  4. Gerekiyorsa: .\scripts\run_sync.ps1
  5. Panel: /dashboard

Durdurma sırası

  1. Zamanlanmış görev varsa: .\scripts\unregister_sync_task.ps1
  2. API pencerelerinde Ctrl + C
  3. Takılı kilit varsa: logs\sync.lock dosyasını silin
  4. Veritabanı silinmez; durdurmak veri kaybı yaratmaz.
API'ler yalnızca 127.0.0.1 üzerinde dinler ve kimlik doğrulama yoktur. Bu bir demo ortamıdır; internete açık sunucuya taşımayın. Üretim için kılavuzun sonundaki güvenlik notlarına bakın.
